# Dashboard module

Vaadin dashboard for the Enceladus AI Gennie demo. It contains the UI views, dashboard services, health indicators, and the backend HTTP client configuration.

Run it from the repository root after building its sibling modules:

```powershell
mvn -pl enceladus-ai-demo-dashboard -am spring-boot:run
```

The root README documents the complete Compose stack, Maven verification, JaCoCo reports, and the other modules.
